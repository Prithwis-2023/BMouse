# BMouse

## Overview
The BrailleDevice project is a collection of Arduino-based applications and libraries designed to assist visually impaired individuals by providing Braille-based input and output solutions. This project includes various implementations for Braille devices, such as Braille mice and Braille displays, supporting both English and Korean languages.

## Project Structure

- **ArduinoUnified/**  
  Contains the unified Arduino sketch supporting both English and Korean Braille (`ArduinoUnified.ino`).

- **BrailleMouseRefactored/**  
  Contains the refactored implementation of the Braille mouse (`BrailleMouseRefactored.pde`) and autosave files.

## Features
- Support for English and Korean Braille input/output.
- Refactored Braille mouse implementation for improved functionality.
- Unified Arduino sketch for multilingual Braille support.
- Braille display library for integration with hardware devices.

## Getting Started
1. Clone the repository to your local machine.
2. Open the desired Arduino sketch (`.ino` or `.pde`) in the Arduino IDE.
3. Upload the sketch to your Arduino device.
4. Follow the instructions in the respective README files for specific modules.
